## Default Permission

Soundhood's on-device downloader: start/cancel a yt-dlp download, read/update the yt-dlp version.

#### This default permission set includes the following:

- `allow-download`
- `allow-cancel`
- `allow-ytdlp-version`
- `allow-ytdlp-update`
- `allow-netcheck`
- `allow-register-listener`
- `allow-remove-listener`
