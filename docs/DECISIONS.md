| Date | Decision | Reason | Evidence |

| 2026-10-28 | Right before the rename that edits, moves or bins a track, the write path checks it again (size, mtime, then blake3 against the pre-image); a playlist is checked against the hash it was read with. A mismatch skips the op "changed since, not changed"; a move or delete rolls its playlist rewrites back. The instant between that check and the rename remains (no compare-and-swap rename exists) | a sync client landing the other device's version mid-write was overwritten | `core/tests/writepath_races.rs` |
| 2026-10-28 | A user op on a file modified less than 10 s ago is skipped ("changed a few seconds ago") unless this device's journal shows it left exactly those bytes (brief §8 item 18). Fixture libraries get a fixed past mtime so they are editable at once | the Proton client rewrites files mid-sync | `writepath_races.rs`; self-test 28/0 |
| 2026-10-28 | Startup recovery decides this device's last open journal entry once. It is finished on record (playlist lines written where unchanged, commit line with source "recovery") only when the disk shows exactly what the change would have left: a tag edit by the checked copy's hash, journaled right before its rename; a move by the same bytes under the new name only (or two names of one inode after a crash inside the unix rename); a delete of a track or a playlist by the same bytes in the bin (or, with the Android app bin, its own name and a bin name one inode after that crash: its own name goes); a file Undo brings back from the app bin by a file under its own name and the bin name gone (or both names one inode: the bin name goes; bytes are not compared, as a live Undo also accepts a bin copy that differs). When the disk can be read and shows neither, the entry is closed "not applied" and never reconsidered; when something cannot be read at that start (a locked file, a bin, or a folder or name in the app bin that cannot be looked at), nothing is written and the next start decides | a crash after the rename left a change Undo could not reach; an identical change made by other means must never be taken for the app's | `kill_write.rs` |
